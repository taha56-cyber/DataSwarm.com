# Data Swarm

## A Living Library of Fish Data

Data Swarm is an interactive web platform built around the exploration, organization, and presentation of information about fish and aquatic ecosystems.

The idea behind Data Swarm is simple: there is an enormous amount of information about aquatic life, but scientific and environmental data can often be difficult to discover, understand, and explore.

Data Swarm aims to bring that information together into an accessible and interactive digital environment.

Instead of treating datasets as nothing more than tables of numbers, Data Swarm combines data, images, descriptions, categories, search tools, and interactive web experiences to make aquatic information easier and more interesting to explore.

The project is focused on fish, but its long-term vision extends much further into oceans, rivers, lakes, coral reefs, marine ecosystems, freshwater ecosystems, climate, biodiversity, and environmental science.

---

# Our Goal

The main goal of Data Swarm is to create a large and organized digital library for aquatic data.

There are thousands of known fish species around the world, and each species has its own habitat, behavior, environment, characteristics, and role within an ecosystem.

Data Swarm is being created to give users a place where they can discover these species and the information connected to them.

The project aims to make aquatic data:

* Easier to discover
* Easier to understand
* Easier to explore
* More visually engaging
* Better organized
* More accessible to students and curious users
* Useful for learning and experimentation

The ultimate goal is to create an environment where users can explore aquatic life through data instead of simply reading static information.

---

# The Idea Behind Data Swarm

The name "Data Swarm" comes from the behavior of fish.

A single fish is one individual.

When many fish move together, they form a school or swarm-like group.

Data can work in a similar way.

One observation may provide a small piece of information.

Hundreds of observations can reveal patterns.

Thousands of observations can reveal larger trends.

Millions of observations can help researchers understand ecosystems and changes happening across the planet.

Data Swarm represents this idea:

Individual information can come together to create a much larger picture.

The project is therefore not only about fish.

It is about how many individual pieces of information can become something much more meaningful when they are organized and connected.

# Interactive Design

Data Swarm is not intended to be a simple static database.

The website uses interactive elements to create an experience that matches the subject of the project.

The login page, for example, contains an interactive fish swarm that reacts to the user's mouse movement.

The animation is designed to make the website feel alive and connected to the concept of Data Swarm.

The goal is to combine information and interaction so that users do not feel like they are simply browsing a spreadsheet.

The interface is part of the experience.

# Data and Images

Visual information is an important part of Data Swarm.

Aquatic organisms can be difficult to understand from text alone.

Images allow users to immediately see the species they are learning about.

The project therefore uses images alongside dataset information to create a stronger connection between the data and the real organism.

Where possible, images can be sourced from openly licensed repositories such as Wikimedia Commons, with licensing and attribution requirements respected.

This allows the project to combine structured information with real-world photographs.
